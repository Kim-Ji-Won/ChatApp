# 4주차 메시지 답장

팀프로젝트 폴더에서 `sh run.sh`를 실행하고 닉네임을 입력한 뒤 **먼저 둘러보기**를 선택한다. **우리들의 아지트**에 들어가면 데모 친구가 “오늘 저녁에 몇 시쯤 만날까?”라고 먼저 말을 건다. 친구 말풍선에 마우스를 올리면 오른쪽에 **답장 버튼(↳)**이 나타난다. 한 번 눌러 답장을 입력한다. 내 일반 메시지에 마우스를 올리면 버튼이 왼쪽에 나타난다. 입력창 위의 ×는 인용만 취소한다. 전송한 답장의 인용 부분을 누르면 현재 대화에서 해당 원문으로 이동한다.

접속 후 대화 목록에서 방을 선택한다. 채팅방 상단의 ‹ 버튼은 목록으로 돌아가며 같은 방을 다시 열면 대화와 입력 중인 내용이 이어진다. 실제 퇴장은 ⋯ 메뉴의 **방 나가기**로 한다. 방 제목 옆 달력 버튼은 **우리의 계획**, 입력창 옆 캐릭터 버튼은 이모티콘을 연다.

| 방향 | 메시지 | 필드 순서 |
| --- | --- | --- |
| 요청 | CHAT_SEND | text |
| 수신 | CHAT_MESSAGE | roomId, sender, text, messageId |
| 요청 | CHAT_REPLY_SEND | requestId, roomId, replyToMessageId, text |
| 수신 | CHAT_REPLY_MESSAGE | roomId, requestId, messageId, sender, text, replyToMessageId, replyToSender, replyToText |
| 오류 | ERROR | code, description, requestId |

자신 또는 같은 방 참가자가 보낸 일반 메시지를 인용할 수 있다. 클라이언트는 원문 ID를 보내고, 답장에는 서버가 확인한 원문 작성자와 내용이 표시된다. 3주차 서버가 보내는 ID 없는 일반 메시지는 이전처럼 채팅과 할 일 생성에 사용할 수 있다.

`sh test.sh`에는 데모의 원문 보관·중복 처리, 인용 클릭, TCP 테스트 상대와의 답장 송수신 및 실패 후 초안 보존 검사가 포함된다. 실제 4주차 서버와의 통합 검사는 백엔드 구현 후 양쪽 클라이언트를 같은 방에 연결해 진행한다.
